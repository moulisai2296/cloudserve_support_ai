📦 Low-Level Component Architecture

End-to-end component breakdown conforming to Setup Guide Section 08 & Build Spec AC-A1 through AC-A10.

B-02 / AC-A2
Ingestion & Normalizer
src/ingest.py
Parses raw payloads across 4 channels (Email, Chat, Docs Comments, Forum) into standard NormalizedTicket Pydantic models. Sanitizes line breaks, handles empty subjects, and preserves customer metadata.
B-03, B-04 / AC-A4
Vector Search & Chunker
src/retrieve.py
Splits 29 KB articles with RecursiveCharacterTextSplitter (size: 800, overlap: 100), prepends titles for semantic grounding, embeds with all-MiniLM-L6-v2 into Chroma (./storage/chroma), and applies a 0.40 similarity threshold.
B-06 / AC-A3
Intent & Urgency Classifier
src/classify.py
Executes prompt classify_v1.txt with meta-llama/llama-3.1-8b-instruct via OpenRouter. Classifies 22 ground-truth intents and 3 urgencies with calibrated confidence and ranked candidate alternatives.
B-07 / AC-A5
Deterministic Policy Router
src/route.py
Enforces 7 hierarchical safety rules (Kill switch, high-risk intent filter, exclusion policy, enterprise SLA, 0.80 confidence floor, doc grounding). If escalated, compiles rich Tier-2 Contextual Escalation Packets.
B-08 / AC-A6
Grounded Answer Generator
src/generate.py
Executes prompt generate_v1.txt strictly grounded in retrieved Chroma passages. Enforces mandatory inline [DOC-ID] citation syntax (extracted via regex). Adapts tone by channel.
B-09 / AC-A7
Pre-Release Safety Guardrails
src/guardrails.py
Enforces Governance Framework Section 4: PII/Secrets leakage check, citation authenticity check against retrieved context, prompt injection detection, and unauthorized commitment blocker. "Block and escalate. Never redact and send."
B-10 / AC-A8
SQLite Governance Audit Store
src/logging_store.py
Persists 100% of automated decisions into SQLite (./storage/decisions.db) conforming to the 15-field Minimum Record Schema. Supports 1:1 coverage reconciliation against processed tickets.
Orchestrator
LangGraph StateGraph
src/graph.py
Compiles all nodes into an executable StateGraph. Manages the unified SupportState and coordinates conditional transitions between auto-respond and escalation branches.
B-05, B-11 / AC-A9
Evaluation Harness & API
evaluation/harness.py & src/api.py
harness.py: Standalone CLI that runs 120-ticket batch evaluation unattended in-memory, computing FCR, Latency, Precision, Citations, and Fairness.
api.py: FastAPI REST service exposing /tickets, /metrics, and /admin/kill-switch.
